# Ways to Contribute

There are many ways to contribute to Vetra UI.

## 🐛 Report Bugs

Found a bug? [Open an issue](https://github.com/flyfishxu/vetra-ui/issues) with:

- Clear, descriptive title
- Steps to reproduce
- Expected vs actual behavior
- Platform (Android/iOS/Desktop/Web)
- Vetra UI version
- Code snippets or screenshots

## 💡 Suggest Enhancements

Have an idea? [Open an issue](https://github.com/flyfishxu/vetra-ui/issues) describing:

- The problem it solves
- Proposed solution
- Examples of where it would be useful

## 📝 Improve Documentation

Documentation improvements are always welcome:

- Fix typos or unclear explanations
- Add examples or usage patterns
- Improve API documentation
- Translate documentation

## 💻 Contribute Code

Ready to code? Follow these steps:

1. [Set up your development environment](setup.md)
2. Review [development guidelines](guidelines.md)
3. [Submit your changes](pull-request.md)
