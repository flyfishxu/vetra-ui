# Requirements

System requirements and prerequisites for using Vetra UI.

## Kotlin Version

- **Minimum**: Kotlin 2.0.0 or higher

## Compose Multiplatform

- **Minimum**: Compose Multiplatform 1.6.0 or higher

## Target Platforms

Vetra UI supports the following platforms:

- ✅ **Android** - Primary platform
- ✅ **iOS** - Full support
- ✅ **JVM Desktop** - Full support
- ✅ **Web (JS)** - Full support
- ✅ **Web (WASM)** - Full support

## Platform-Specific Requirements

### Android

- Minimum SDK: 21 (Android 5.0+)
- Target SDK: Latest recommended

### iOS

- Minimum iOS version: 14.0
- Xcode 14.0+ recommended

### Desktop (JVM)

- Java 11 or higher recommended
- No additional requirements

### Web

- Modern browsers (Chrome, Firefox, Safari, Edge)
- No additional requirements

## Development Tools

- **Android Studio** or **IntelliJ IDEA** (recommended)
- **Kotlin Multiplatform Mobile** plugin (for iOS support)
